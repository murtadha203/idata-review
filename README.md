# موقع مراجعة اللوحات

يعرض لوحة البيانات **كما ستُنشر تماماً**، ويضيف فوقها طبقةَ تعليق. يراجع الفريق
قبل النشر، ويعلّق كلٌّ على الموضع الذي يقصده، ويعطي تقييمه — **ولا تُنشر لوحةٌ
إلّا بعد أن يُجيزها المراجعون**.

## لماذا لا PDF ولا Word

الملفّ المصدَّر ينقل **المضمون** لا **الصفحة**: يعيد سكب المحتوى في تدفّق فقرات،
فيراجع السينيور شيئاً غير الذي سيراه القارئ. وهذا الموقع يخدم صفحة HTML **بلا
مساس**، ويحقن طبقةً فوقها.

## التشغيل محلّياً

```bash
python -X utf8 server.py          # http://127.0.0.1:8080
```

يحتاج بايثون 3.9 فأحدث. **بلا اعتماديّات** — المكتبة القياسية وحدها.

## سجلّ الفريق

**أسماء الدخول هي كلمات المرور الوحيدة، فلا تدخل المستودع.** تُقرأ من
`config/team.json` — وهو خارج المستودع — أو من متغيّر البيئة `TEAM_JSON`.

```json
[
  { "username": "name_1234", "name": "الاسم المعروض", "role": "uploader" },
  { "username": "other_5678", "name": "اسم آخر",      "role": "reviewer" }
]
```

| الدور | يستطيع |
|---|---|
| `uploader` | رفع اللوحات · التعليق |
| `reviewer` | التعليق · التقييم من عشرة · الإجازة للنشر |

**واسم الدخول لا يظهر إلّا في شاشة الدخول** — والتعامل في كلّ ما عداها بالاسم.

## متغيّرات البيئة

| | |
|---|---|
| `PORT` | المنفذ (تضبطه الاستضافة) |
| `HOST` | `0.0.0.0` عند الاستضافة، `127.0.0.1` محلّياً |
| `DATA_DIR` | مسار القرص الدائم — تحته القاعدة واللوحات والمكتبات |
| `TEAM_JSON` | السجلّ، بديلاً عن الملفّ |

## كيف تنجو التعليقات من إعادة الرفع

كلّ تعليقٍ مربوطٌ بـ**هوية** العنصر لا بترتيبه: مفتاحٌ مشتقٌّ من نوع القسم
وعنوانه، وداخله موضعٌ أدقّ — بطاقةٌ بعينها، أو نقطةٌ في رسم، أو نصٌّ محدَّد
يُعاد إيجاده **بنصّه**.

فإضافةُ رسمٍ في الأعلى لا تزحزح شيئاً. وإن حُذف العنصر أو تغيّر عنوانه، يظهر
التعليق موسوماً **«العنصر لم يعد موجوداً»** — **ولا يُنقل إلى غيره صامتاً**،
لأنّ تعليقاً على الموضع الخطأ أسوأ من تعليقٍ بلا موضع.

## تخفيف الصفحة

اللوحة تُضمّن محرّك الرسم داخلها (نحو 800 كيلو). فتُنقل عند الرفع إلى ملفٍّ
مستقلٍّ **اسمُه بصمةُ محتواه**، ويُخدَم بترويسة تخزينٍ سنوية. فاللوحة تنزل إلى
نحو 120 كيلو، **وكلّ اللوحات تتشارك النسخة نفسها**.

## البنية

```
server.py            الخادم كلّه — بايثون قياسيّ + SQLite
static/app.css       القائمة والدخول
static/list.js       التصفية والفرز
static/review.js     طبقة التعليق المحقونة في اللوحة
static/review.css
config/team.json     السجلّ — خارج المستودع
data/                القاعدة واللوحات والمكتبات — خارج المستودع
```

## ما يحتاج عملاً قبل التوسّع

- **تنبيهات**: لا أحد يعلم أنّ لوحةً رُفعت أو تعليقاً كُتب.
- **إعلامُ المراجع أنّ إجازته سقطت** عند رفع نسخةٍ جديدة — تسقط اليوم بصمت.
- **نسخة احتياطية تلقائية**: التصدير موجودٌ ويدويّ (`/export`).
